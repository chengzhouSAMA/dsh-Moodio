---
name: trigger
description: 什么时候该调用 moodio
---

在以下情况调用：

- 需要根据音乐调整行为（配乐、剪辑点、播放列表排序、场景氛围）。
- 用户问"这首歌什么情绪""哪里最high""副歌是不是更激动"。
- 需要把音频作为多模态输入的一部分（视频/播客/游戏）并提取情绪维度。
- 需要可复现的、带数值的情绪标签，而不是让 LLM 凭歌名猜。

不要在以下情况调用：

- 只需要音频元数据（时长/码率）——那是 ffprobe 的活。
- 需要曲风分类、乐器识别、歌词转写——本项目不提供。
- 需要"人群平均评分"级别的绝对校准——本模型给的是相对坐标，绝对值有偏。
